
# Description
chat-java-sockets is a repository of a chat system which is based on TCP client-server model using sockets and multithreading in JAVA

# Motivation
This project was a part of Data Communication and Networking and the motivation was to learn JAVA programming language Threads, Sockets and Network Programming.

# Features
1. Two major classes one for Server and one for Client are connected using Sockets (java.net.Socket class available in java)
2. Multiple clients are supported at the same time using threads to handle each request.
3. Server can broadcast same message to every client.
4. Server/Client can see list of active/online clients.
5. Clients can login/logout.
6. Clients can chat with each other as well as Server.

# Tech Stack
1. Java
2. Sockets
3. Threads
